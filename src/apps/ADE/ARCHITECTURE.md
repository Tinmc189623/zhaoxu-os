# ADE 桌面架构要求（用户原文存档）

- `src/apps/ADE/` = desktop env（桌面环境）
- `src/apps/ADE/winmgr/` = 窗口管理器
- 现在，你正在重新开发一款桌面，必须学习kde这种成熟的桌面，且风格为aqua，应用程式不得打包在桌面中，桌面只向外提供api接口，窗口管理器通过系统api的渲染接口来渲染，它不自己绘制页面，字体：MiSans、MiSans Global、Inter，字体存在于系统中，由系统提供，而不是由桌面提供。
- 把这段话存在一个文件里，以便后续调用，现在开始加固内核，让它支持多处理器多线程调度器等一大堆功能，应避免空指针什么也指针什么内存泄漏等问题。

## 命名（AGENTS.md 规则 1）

- 内核：`Yuanshuo Kernel`
- 操作系统：`Zhaoxu OS`
- Shell：`csh`
- 桌面：`ADE`（风格：Aqua）
- 窗口管理器：`DWM`

## 架构边界

- ADE 不得打包应用；应用独立存在，ADE 只向外提供 API。
- DWM 通过系统渲染 API 合成窗口，不自行绘制页面。
- 字体（MiSans、MiSans Global、Inter）由系统提供，桌面不自带字体。

## 内核加固目标

- 多处理器（SMP）支持。
- 多线程与抢占式调度器。
- 避免空指针、野指针、内存泄漏等问题。
