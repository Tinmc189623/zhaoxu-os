# ext4 Primary Filesystem (M0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the complete ext4 implementation out of the kernel into Ring 3 `/bin/ext4fs`, and have the installer and VFS use it over RPC; on an installed disk the kernel exists only in the ext4 partition, with FAT32 kept only for the ESP/compatibility; fix legacy BIOS booting from the ISO.

**Architecture:** `src/fs/ext4/` is the OS-independent ext4 core (read, write, format, later journal/checksums), reaching block devices and memory through the read/write/flush/alloc/log callbacks of `ext4_env`. The Ring 3 service `/bin/ext4fs` does I/O with new trusted `blk_*` syscalls; the kernel allocates a control page plus a data page and passes physical addresses through `spawn_arg`. The kernel VFS forwards `/mnt` requests to the service; the installer hands the ext4 partition to the service and only writes MBR/GPT/ESP/stage2 itself.

**Tech Stack:** C (freestanding, kernel and Ring 3), FASM (BIOS boot), Ruby (all build/test scripts, rule 6), QEMU + OVMF/SeaBIOS, e2fsprogs (host tests).

**Spec:** `docs/superpowers/specs/2026-11-11-ext4-primary-design.md`

## Global Constraints

- Kernel name `Yuanshuo`, system `Zhaoxu OS`, shell `8sh`, desktop `Aqua Desktop Environment` (Aqua), window manager `Desktop Window Manager`; these names must not be rewritten.
- Build inside WSL2 `Ubuntu-26.04` with the working directory `src/`; Ruby scripts run from the Windows side (WSL has no ruby).
- The kernel binary must not contain ext4/driver/application code; `nm out/kernel.elf | grep -E '^.* ext4_'` must be empty.
- The kernel may only live in the ext4 partition: no kernel ELF in MBR/stage1/stage2/ESP; the ESP holds only `EFI/BOOT/BOOTX64.EFI`.
- The filesystem must support both MBR and GPT; the ESP must be FAT32.
- One file does one job; all new scripts are Ruby and generated by AI.
- No kernel-mode ext4 fallback: at the end of M0 the kernel no longer compiles `kernel/fs/ext4*.c`.
- The commit steps are checkpoints: **run `git commit` only when the user explicitly authorizes it**; without authorization, run `git diff --stat` instead and stop to report.
- Run `make -j4` at least once after every change; for boot-related changes also run the corresponding QEMU smoke.

Global replacement (only in `src/fs/ext4/`): `kmalloc(` → `ext4_alloc(`, `kfree(` → `ext4_free(`, `kprintf(` → `ext4_logf(`.

Mapping rules for block I/O (the env's `base` is the partition start sector, `offset` is the byte offset inside the partition):

- After mount: `block_disk_read(disk, lba, count, buf)` →
  `ext4_env()->read(disk, g_ext4.volume_base, (u64)lba * 512, buf, count * 512)`.
  Writes use `->write` the same way.
- Before mount/format/probe: use the `base` from the call arguments, not `g_ext4`.
  Put one local helper in each of `ext4_mount.c` / `ext4_format.c`:
  ```c
  static int raw_read(int disk, u64 base, u64 offset, void *buffer, u32 length)
  {
      return ext4_env()->read(disk, base, offset, buffer, length);
  }
  static int raw_write(int disk, u64 base, u64 offset, const void *buffer,
                       u32 length)
  {
      return ext4_env()->write(disk, base, offset, buffer, length);
  }
  ```
- `block_disk_count()` → `ext4_env()->disk_count()`;
  `block_disk_sectors(d)` → `ext4_env()->disk_sectors(d)`;
  `block_disk_flush(d)` → `ext4_env()->flush(d)`.

Note: in `ext4_read_super(disk, base, sb)` the original
`block_disk_read(disk, base + 2, EXT4_SB_SECTORS, sb)` must become
`raw_read(disk, base, 1024, sb, 1024)` (offset 1024 inside the partition).

Also replace the kernel-only headers: remove `#include <block.h>`, `<mem.h>`,
and keep `<kprintf.h>` only in `ext4_env.c`; the other files include only

- [ ] **Step 6: Add `ext4_write_file_contig`**

Add it in `ext4_write.c` (reusing the existing `ext4_create_node`,
`inode_init_extents`, `inode_extent_append`, `ext4_write_block`):

```c
int ext4_write_file_contig(const char *path, const u8 *data, u64 size,
                           u32 *first, u32 *blocks)
{
    char parent[256];
    char name[256];
    if (split_parent(path, parent, name) != 0)
        return -1;
    u32 parent_ino = 0;
    if (ext4_lookup(parent, &parent_ino) != 0)
        return -1;

    u32 count = (u32)((size + g_ext4.block_size - 1) / g_ext4.block_size);
    u32 start = 0;
    if (ext4_alloc_run(count, &start) != 0)
        return -1;

    u32 ino = 0;
    if (ext4_create_node(parent_ino, name, 0100644, EXT4_FT_REG_FILE,
                         &ino) != 0)
        return -1;
    u8 inode[256];
    if (ext4_read_inode_raw(ino, inode) != 0)
        return -1;
    inode_init_extents(inode);
    if (inode_extent_append(inode, 0, start, count) != 0)
        return -1;
    inode_set_size(inode, (u32)size);
    ext4_put32(inode + EXT4_INODE_BLOCKS_OFF, count * 8);

    u8 *block = ext4_alloc(g_ext4.block_size);
    if (!block)
        return -1;
    for (u32 i = 0; i < count; i++) {
        u32 bytes = g_ext4.block_size;
        if ((u64)(i + 1) * g_ext4.block_size > size)
            bytes = (u32)(size - (u64)i * g_ext4.block_size);
        memset(block, 0, g_ext4.block_size);
        memcpy(block, data + (u64)i * g_ext4.block_size, bytes);
        if (ext4_write_block(start + i, block) != 0) {
            ext4_free(block);
            return -1;
        }
    }
    ext4_free(block);
    if (ext4_write_inode_raw(ino, inode) != 0)
        return -1;
    if (first)
        *first = start;
    if (blocks)
        *blocks = count;
    return ext4_sync();
}
```

`split_parent`/`inode_set_size`/`EXT4_INODE_BLOCKS_OFF` are already inside the core;

static void host_free(void *p) { free(p); }

`src/apps/ext4fs/arena.c`: a fixed 2 MiB static arena, first-fit with free-block coalescing.
The service is long-lived, so `free` must really reclaim memory; otherwise repeated reads
will exhaust the 2 MiB:

```c
#include <types.h>

#define ARENA_BYTES (2u * 1024u * 1024u)

struct arena_block {
    u32 size;
    u32 free;
    struct arena_block *next;
};

static u8 g_arena[ARENA_BYTES] __attribute__((aligned(16)));
static struct arena_block *g_head;

static void arena_init(void)
{
    g_head = (struct arena_block *)g_arena;
    g_head->size = ARENA_BYTES - sizeof(struct arena_block);
    g_head->free = 1;
    g_head->next = 0;
}

void *arena_alloc(u32 bytes)
{
    if (!g_head)
        arena_init();
    bytes = (bytes + 15u) & ~15u;
    for (struct arena_block *block = g_head; block; block = block->next) {
        if (!block->free || block->size < bytes)
            continue;
        if (block->size >= bytes + sizeof(struct arena_block) + 16u) {
            struct arena_block *rest =
                (struct arena_block *)((u8 *)(block + 1) + bytes);
            rest->size = block->size - bytes - sizeof(struct arena_block);
            rest->free = 1;
            rest->next = block->next;
            block->next = rest;
            block->size = bytes;
        }
        block->free = 0;
        return block + 1;
    }
    return 0;
}

void arena_free(void *pointer)
{
    if (!pointer)
        return;
    struct arena_block *block = (struct arena_block *)pointer - 1;
    block->free = 1;
    for (struct arena_block *item = g_head; item; item = item->next) {
        if (item->free && item->next && item->next->free) {
            item->size += sizeof(struct arena_block) + item->next->size;
            item->next = item->next->next;
        }
    }
}

    u64 value = 0;
    if (!text)
        return 0;

        text += 2;

struct list_item { u8 name_len; u8 is_dir; u16 pad; u64 size; char name[]; };
struct list_ctx {
    u8 *data; u32 cap; u32 used; u32 index; u32 skip; u32 next; u32 count;
};

static void list_cb(const char *name, u64 size, int is_dir, void *context)
{
    struct list_ctx *ctx = context;
    u32 index = ctx->index++;
    if (index < ctx->skip)
        return;
    u32 name_len = (u32)u_strlen(name);
    u32 need = (16u + name_len + 1u + 15u) & ~15u;
    if (ctx->used + need > ctx->cap)
        return;
    struct list_item *item = (struct list_item *)(ctx->data + ctx->used);
    item->name_len = (u8)name_len;
    item->is_dir = (u8)(is_dir != 0);
    item->pad = 0;
    item->size = size;
    memcpy(item->name, name, name_len + 1);
    ctx->used += need;
    ctx->count++;
    ctx->next = index + 1;
}

static int handle(struct fs_rpc *rpc, u8 *data)
{
    switch (rpc->op) {
    case FS_OP_MOUNT: {
        if (ext4_mount() != 0)
            return -1;
        const char *label = ext4_label();
        usize n = 0;
        while (label && label[n] && n + 1 < sizeof(rpc->label)) {
            rpc->label[n] = label[n];
            n++;
        }
        rpc->label[n] = 0;
        return 0;
    }
    case FS_OP_STAT: {
        int is_dir = 0;
        u64 size = 0;
        if (ext4_stat(rpc->path, &is_dir, &size) != 0)
            return -1;
        rpc->value0 = is_dir ? 1 : 0;
        rpc->value1 = size;
        return 0;
    }
    case FS_OP_LIST: {
        struct list_ctx ctx = { data, FS_DATA_SIZE, 0, 0,
                                (u32)rpc->offset, 0, 0 };
        if (ext4_list(rpc->path, list_cb, &ctx) != 0)
            return -1;
        rpc->length = ctx.used;
        rpc->value0 = ctx.next;
        rpc->value1 = ctx.count;
        return 0;
    }
    case FS_OP_READ: {
        u64 got = 0;
        if (!rpc->length)
            return 0;
        if (ext4_read_at(rpc->path, rpc->offset, data, rpc->length,
                         &got) != 0)
            return -1;
        rpc->length = (u32)got;
        return 0;
    }
    case FS_OP_WRITE: {
        u64 end = rpc->offset + rpc->length;
        if (end > FS_WRITE_MAX || rpc->length > FS_DATA_SIZE)
            return -1;
        memcpy(g_write_buf + rpc->offset, data, rpc->length);
        if (end < rpc->value0)
            return 0;
        return ext4_write_file(rpc->path, g_write_buf, rpc->value0);
    }
    case FS_OP_WRITE_CONTIG: {
        u64 end = rpc->offset + rpc->length;
        if (end > FS_WRITE_MAX || rpc->length > FS_DATA_SIZE)
            return -1;
        memcpy(g_write_buf + rpc->offset, data, rpc->length);
        if (end < rpc->value0)
            return 0;
        u32 first = 0;
        u32 blocks = 0;
        if (ext4_write_file_contig(rpc->path, g_write_buf, rpc->value0,
                                   &first, &blocks) != 0)
            return -1;
        rpc->value0 = first;
        rpc->value1 = blocks;
        return 0;
    }
    case FS_OP_UNLINK:
        return ext4_unlink(rpc->path);
    case FS_OP_SYNC:
        if (ext4_sync() != 0)
            return -1;
        if (g_install_active) {
            ext4_state_restore(g_saved);
            g_install_active = 0;
        }
        return 0;
    case FS_OP_FORMAT: {
        u64 encoded = rpc->value0;
        int disk = (int)(encoded >> 48);
        u64 base = encoded & 0xFFFFFFFFFFFFULL;
        g_saved = ext4_state_save();
        g_install_active = 1;
        if (ext4_format_volume(disk, base, (u32)rpc->value1,
                               rpc->label) != 0 ||
            ext4_mount_at(disk, base) != 0) {
            ext4_state_restore(g_saved);
            g_install_active = 0;
            return -1;
        }
        return 0;
    }
    default:
        return -1;
    }
}
```

Main loop:

```c
void ext4fs_service(struct fs_rpc *rpc, u8 *data)
{
    long id = sys_shm_create(FS_WRITE_MAX);
    if (id <= 0)
        return;
    g_write_buf = (u8 *)sys_shm_map(id);
    if (!g_write_buf)
        return;
    for (;;) {
        if (rpc->state == FS_STATE_REQUEST) {
            rpc->status = handle(rpc, data);
            __sync_synchronize();
            rpc->state = FS_STATE_DONE;
        } else {
            sys_sleep(1);
        }
    }
}
```

The write buffer lives in an 8 MiB shared-memory object (`SHM_MAX_PAGES` = 2048 pages),
so it does not eat into the user program's 4 MiB static mapping quota.

WRITE works as "the kernel sends chunks in order and the service commits the whole file
on the last packet"; `FS_WRITE_MAX` of 8 MiB covers `KERNEL.ELF` (about 300 KiB) and
`WQY.TTC` (about 5 MiB). Ordinary `/mnt` writes take the same path.

- [ ] Step 5: Write `iso-bios.rb`

```ruby
#!/usr/bin/env ruby
# iso-bios.rb -- backfill the BIOS stage2 kernel/font parameters inside the ISO (rule 6).
iso = ARGV[0] or abort "usage: iso-bios.rb <iso>"
data = File.binread(iso)
SECTOR = 2048

def le32(s, o) = s[o, 4].unpack1("V")
def le16(s, o) = s[o, 2].unpack1("v")

def entries(data, lba, size)
  raw = data[lba * SECTOR, size]
  out = []
  pos = 0
  while pos < raw.bytesize
    len = raw.getbyte(pos)
    break if len.nil? || len.zero?
    rec = raw[pos, len]
    name_len = rec.getbyte(32)
    name = rec[33, name_len].to_s
    name = "." if name_len == 1 && rec.getbyte(33) == 0
    name = ".." if name_len == 1 && rec.getbyte(33) == 1
    out << { name: name, lba: le32(rec, 2), size: le32(rec, 10),
             final: (rec.getbyte(25) & 0x80).zero? }
    pos += len
  end
  out
end

def find(list, name)
  item = list.find { |e| e[:name].casecmp?(name) }
  abort "iso-bios: #{name} missing" unless item
  abort "iso-bios: #{name} is multi-extent" unless item[:final]
  item
end

pvd = data[16 * SECTOR, SECTOR]
abort "iso-bios: no ISO9660 PVD" unless pvd[1, 5] == "CD001"
root_lba = le32(pvd, 158)
root_size = le32(pvd, 166)
root = entries(data, root_lba, root_size)
install = find(root, "INSTALL")
install_entries = entries(data, install[:lba], install[:size])
kernel = find(install_entries, "KERNEL.BIN")
font = find(install_entries, "WQY.TTC")
boot = find(root, "BIOS.IMG")

stage2_offset = boot[:lba] * SECTOR + 1024
magic = "ZBOOTPRM"
index = data.index(magic, stage2_offset)
abort "iso-bios: ZBOOTPRM missing" unless index && index < stage2_offset + 0x8000
patch = [kernel[:lba], kernel[:size], 0, 1, font[:lba], font[:size]]
               .pack("Q<Q<Q<Q<Q<Q<")
data[index + 8, patch.bytesize] = patch
File.binwrite(iso, data)
puts "iso-bios: kernel LBA #{kernel[:lba]}, font LBA #{font[:lba]}"
```

(`entries` needs to read the 32-bit name-length field of the directory record; reject
multi-extent with flags bit 7. The PVD offsets 156/166 hold the root directory record;
the code above uses 158/166 for the LBA/length — the two differ by 2 bytes, so validate
against the ISO9660 structure once before running the real implementation.)

### Task 7: Carry the font into ext4 during BIOS install

**Files:**
- Modify: `src/boot/bios_stage2.asm`
- Modify: `src/tools/iso-bios.rb`
- Modify: `src/kernel/fs/install.c` (font source)

**Interfaces:**
- Consumes: Task 6's parameter block and CD/HDD reads.
- Produces: `boot_info.font_phys/font_size` valid when booting the BIOS ISO.

- [ ] Step 1: Parameter block fields

The font fields are already defined in the `ZBOOTPRM` block from Task 6 Step 4:
`param_font_lba`, `param_font_bytes`. `iso-bios.rb` already backfills them.
On the install disk (HDD) the installer zeroes both fields.

- [ ] Step 2: Segment-load the font into high memory

No unreal mode; reuse the existing "real-mode read into a low buffer → protected-mode copy
to high memory" pattern, run in batches (font ≤ 8 MiB, each batch ≤ 448 KiB):

```asm
load_font:
        cmp     qword [param_font_bytes], 0
        je      .done
        cmp     qword [param_font_bytes], FONT_MAX
        ja      .done
        mov     dword [font_done], 0
.loop:
        ; remaining bytes = param_font_bytes - font_done
        mov     eax, dword [param_font_bytes]
        sub     eax, [font_done]
        jz      .done
        cmp     eax, FONT_CHUNK          ; 448 KiB
        jbe     .size_ok
        mov     eax, FONT_CHUNK
.size_ok:
        ; compute this batch's sector count (by device sector size)
        ; read LBA = param_font_lba + font_done / 2048 (CD uses 2 KiB units)
        call    read_font_chunk          ; read into 0x10000
        ; enter protected mode and copy the 0x10000 chunk to 0x04000000+font_done
        call    pm_copy_font
        add     [font_done], eax
        jmp     .loop
.done:
        mov     rax, 0x04000000
        mov     [boot_info + FONT_PHYS], rax
        mov     rax, [param_font_bytes]
        mov     [boot_info + FONT_SIZE], rax
```

`pm_copy_font`/`read_font_chunk` share the GDT and page tables with the existing
mode-switching code in `load_kernel`, and must save/restore `esp` and the segment
registers; after returning to real mode each time, run `xor ax,ax; mov ds/es/ss,ax` again.

- [ ] Step 3: Kernel reserves the font pages

After building the free page tables, `pmm_init` marks `boot_info.font_phys` through
`font_size` bytes as used (rounded up to whole pages), so the allocator does not overwrite
the font. The UEFI path benefits too (it previously relied on the firmware memory type).

- [ ] Step 4: Installer font priority

`install.c` keeps:

```c
const u8 *font = (const u8 *)(uintptr_t)info->font_phys;
if (!font || font_size < 13)
    font_size = 0;
```
(BIOS now fills `font_phys` too; with no font, ext4 does not write `WQY.TTC`.)

- [ ] Step 5: Verification

Boot BIOS from the ISO; the serial log should print the font size. After `install mbr`,
the target disk's ext4 root should contain `/WQY.TTC` (check with host `debugfs -R "ls /"`).

- [ ] Step 6: Checkpoint

Run: `git diff --stat src/boot src/tools src/kernel/fs/install.c src/kernel/mem/pmm.c`
